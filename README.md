### What to look at

**[TheTeacher](https://github.com/yepun01/theteacher)** is a lesson runtime in production. Prose, a 3D world, an executable code editor and an AI tutor share one screen. After the student's code runs, the tutor reads the real position in the simulation and asks its next question from that result. Built on Next.js 16 and 5 Cloudflare Workers, with the student's Python confined to a sandboxed runner so the main origin never needs 'unsafe-eval'. [Try it](https://theteacher2.sofianehutao.workers.dev).

**[claude-code-config](https://github.com/yepun01/claude-code-config)** is the tooling I develop with every day. 9 specialized agents, 15 skills, 18 lifecycle hooks, 22 ADRs, around 10k lines. Every technical claim an agent produces carries an evidence marker, weighted into a justification denominator.

**[Machine-Learning_trading_bot](https://github.com/yepun01/Machine-Learning_trading_bot)** came out of a 24h hackathon. Pure NumPy, no framework, written from scratch. 5th out of ~100 participants, and the ML approach won against the classic rule-based ones.

**[EWR](https://github.com/yepun01/EWR)** is a browser coding game where you progress by writing code, inspired by The Farmer Was Replaced.
